# Операционная аналитика

## Активная версия

- Маршрут: `/operations`
- Страница: `operations.html`
- Стили: `assets/css/pages/operations.css`
- Скрипт: `assets/js/pages/operations.js`
- Идентификатор shell-навигации: `operations`

Это единственная версия операционной аналитики, отображаемая в боковом меню.
Файлы `operations.css` и `operations.js` также содержат общие компоненты, которые подключаются на страницах финансов, бюджета, логистики и договоров.

## Архивная версия

- Маршрут: `/operations_archiv`
- Страница: `operations_archiv.html`
- Идентификатор страницы: `operations-archive`

Архивная версия сохранена для возможного повторного использования, но намеренно не добавлена в боковое меню. Для возврата страницы в навигацию нужно добавить отдельный пункт в `assets/js/navigation.js`; активный маршрут `/operations` при этом менять не следует.
