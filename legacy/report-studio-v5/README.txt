BNT Report Studio Demo v5

Запуск на Windows:
1. Распакуйте ZIP.
2. Дважды нажмите start.bat.
3. Откроется http://localhost:8080

Можно также открыть BNT_Report_Studio_Demo.html напрямую — это автономная версия без сервера.

Структура:
- index.html — интерфейс
- app.js — логика демо
- styles.css — оформление
- data.json — демонстрационные данные 2024–2026 из ранее предоставленных выгрузок
- report-data.json — реальные контрольные значения из PDF-форм заказчика
- templates.json — встроенные шаблоны отчетов
- logo.svg — логотип ITP Portal

Что добавлено в v5:
- каждый готовый шаблон открывает свою форму, период, источник и набор блоков;
- реальные контрольные цифры для CF, IS, «Общих показателей» и «Консолидированных показателей БНТ»;
- отдельный производственный источник Pelogas;
- создание отдельного графика по любому показателю из 1С;
- создание отдельного графика по производственному показателю Pelogas;
- редактирование значения только внутри конкретного шаблона без изменения исходных данных;
- отдельное редактирование исходного значения 1С на странице «Данные»;
- автоматический пересчет графиков после корректировки;
- экспорт всего отчета и отдельного блока в Excel (.xls, открывается Excel);
- PDF/печать всего отчета и отдельного блока;
- JSON-экспорт/импорт шаблона вместе с пользовательскими графиками и локальными корректировками;
- автоматические рассылки: ежедневно / еженедельно / ежемесячно, время, получатели, PDF / Excel / оба формата;
- отдельная страница «Рассылки» и тестовая отправка;
- синхронизация 1С + Pelogas в одном интерфейсе.

Важно:
Автоматическая отправка e-mail в этом frontend-демо сохраняет конфигурацию и имитирует тестовую отправку. Для промышленной версии требуется backend-планировщик и SMTP/почтовый сервис.
